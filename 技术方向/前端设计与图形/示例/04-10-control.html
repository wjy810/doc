控制一段动画：播放、暂停、反向、取消、加速、中途改变目标

Web Animations API 返回的动画对象可以随时控制；“改变目标”从当前看到的位置出发，不会跳回起点。

队列：三步依次进行，一次取消整个队列

每一步等上一步结束（await finished）；AbortController 让取消能传到还没开始的步骤。

清理与页面隐藏

离开页面或组件销毁时，取消动画、移除事件；页面隐藏时暂停持续运行的动画。

200 个点同时运动：transform 与 left／top 的帧时间

改变 left／top 每一帧都要重新布局；改变 transform 通常只需要合成。
