- 锚点 `part-N`、`chNN`、`appendix-x`、`ref-bNN`；资料 B01… 按首次引用顺序编号。
- `**标签**：`（冒号在粗体外）；并列用顿号；中英文、数字之间加空格；全角标点；范围用“—”；“／”。

## 3. 每册的工作流程

1. 读原稿章节；列知识点：`awk -F'\t' '$6 ~ /目标文件名/' tools/coverage/前端与UIUX设计进阶全景手册.tsv`。
2. 设计示例（`示例/NN-MM-name.html`），测试并截图到 `图片/NN-MM-name.png`。
3. 写正文；`python3 tools/check_docs.py 文件.md`（只允许“尚未写的兄弟分册”导致的 E106）。
4. `python3 tools/check_coverage.py check --part <原稿章号> --missing`：真缺的补内容；措辞不同的用 `python3 tools/check_coverage.py set 编号 "词1｜词2"` 登记等价写法。目标 100%。
5. 粗体标点：`python3 tools/示例测试/fix_bold.py 文件.md`；资料重编号：`python3 tools/示例测试/renumber_refs.py 文件.md`。
6. 提交、推送。

## 4. 示例测试环境（新容器需重新安装）

```bash
cd tools/示例测试 && npm install          # 依赖版本与示例里的 jsDelivr 地址一致；node_modules 不入库
cd 技术方向/前端设计与图形
NODE_PATH=$(npm root -g) node ../../tools/示例测试/run_example.js 示例/X.html --out 图片/X.png \
  --width 1180 --height 900 [--wait 毫秒] [--actions ../../tools/示例测试/actions/x.js] [--selector 元素] [--allow 正则] [--webgpu] [--dpr 2]
```

- 容器里预装了 Chromium 与 Playwright（`require('playwright')` 可用，不要再装）。脚本把 jsDelivr 请求映射到本地 `node_modules`，其他外部请求会被拦截并报告。
- 需要 HTTP 服务时：`(python3 -m http.server 8765 --bind 127.0.0.1 &)`，用完 `pkill -f "http.server 8765"`（退出码 144 无害）。
- 允许出现 “GPU stall due to ReadPixels” 警告（用 `--allow`）。
- 拼图：`COLS=2 python3 tools/示例测试/compose.py 输出.png 图1.png "说明1" 图2.png "说明2"`（需要 Pillow 与文泉驿字体）。
- WebGPU：加 `--webgpu` 走 SwiftShader 软件适配器；WebGPU 画布截不进截图，要用读回像素的方式验证；three.js WebGPURenderer 在这个环境会丢设备，但着色器生成可用。
- three.js 0.186.1 注意：没有 PCFSoftShadowMap（用 PCFShadowMap）；阴影贴图默认写入背面（要演示阴影痤疮需 `shadowSide = FrontSide`）；GLTFLoader 会把节点名 “Cube.001” 改成 “Cube001”；手册地址改为 `https://threejs.org/manual/pages/<slug>.html`，文档地址 `https://threejs.org/docs/pages/X.html`；多步渲染统计用 `renderer.info.autoReset = false` 并每帧 `info.reset()`。
- 事实核对：WebFetch 解析不了 MDN，改用 curl 下载页面提取 Baseline 文字；iquilezles.org 需要浏览器 UA 和结尾斜杠。
