1 顶点处理与插值

三个顶点各带一种颜色。顶点之间的颜色由 GPU 自动插值：越靠近哪个顶点，越像它的颜色。

// 顶点着色器：每个顶点运行一次
in vec2 position; in vec3 color;
out vec3 vColor;  // 交给光栅化插值
void main() {
  vColor = color;
  gl_Position = vec4(position, 0.0, 1.0);
}
// 片元着色器：每个像素运行一次
in vec3 vColor;  out vec4 outColor;
void main() { outColor = vec4(vColor, 1.0); }

2 光栅化：三角形被切成片元

同一个三角形，只用 30 × 20 个像素画出，再放大显示。每个小方块就是一个片元，片元着色器为每个片元算出一种颜色。

3 UV 坐标与纹理采样

左：把 UV 直接显示为颜色（u 越大越红，v 越大越绿）。右：用 UV × 3 在一张纹理中取色，纹理重复了三次。

in vec2 vUv;  uniform sampler2D map;
void main() {
  if (vUv.x < 0.5)   // 左半边：UV 显示为颜色
    outColor = vec4(vUv.x * 2.0, vUv.y, 0.0, 1.0);
  else              // 右半边：纹理采样
    outColor = texture(map, vUv * vec2(2.0, 1.0) * 3.0);
}
