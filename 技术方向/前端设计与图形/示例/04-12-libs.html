CSS

简单的过渡与进场动画，不需要任何库

.chips span {
  animation: rise .4s both;
  animation-delay: calc(var(--i) * 60ms);
}
@keyframes rise {
  from { opacity: 0; transform: translateY(12px); }
}
/* 弹簧：用 linear() 写出的回弹曲线（见 05 章） */

Motion

简洁的函数接口，内置弹簧、滚动与进入视口

const { animate, stagger } = Motion;
animate(chips, { opacity: [0, 1], y: [12, 0] },
        { delay: stagger(0.06), duration: 0.4 });
animate(box, { x: [0, distance] },
        { type: 'spring', stiffness: 300, damping: 18 });

GSAP

时间线编排复杂的先后与重叠，插件丰富

gsap.from(chips, { opacity: 0, y: 12,
                   stagger: 0.06, duration: 0.4 });
gsap.timeline()
  .to(box, { x: distance, duration: 0.5,
             ease: 'back.out(1.7)' })
  .to(box, { rotation: 90, duration: 0.3 }, '-=0.1');
